### 🚀 Featured Projects

🔹 **[PCAP Analyzer](https://github.com/larenmatjoe)** | *Python, TypeScript, React, Next.js, Scapy, YARA, Scikit-learn*
> Full-stack network forensics platform processing multi-GB PCAP files. Integrates a YARA rule matching engine alongside ML-based anomaly detection, scanning 10+ protocol layers with interactive IP relationship graphs.

🔹 **[Telnet Honeypot](https://github.com/larenmatjoe)** | *Python, Firebase, iptables, Linux*
> Modular honeypot emulating 15+ Linux commands to maximize attacker dwell time. Features a 3-component architecture that logs 500+ unique IPs to Firebase and blocks malicious IPs via iptables in <5 seconds.

🔹 **[DiskFail](https://github.com/larenmatjoe)** | *Python, Scikit-learn, Next.js, TypeScript*
> Three-tier full-stack system monitoring 30+ SMART attributes per disk. Uses an ML pipeline to predict impending hardware failures with sub-second inference time across fleet-wide concurrent nodes.

🔹 **Splunk SIEM Deployment** | *Splunk Enterprise, Linux, SPL*
> Deployed enterprise SIEM correlating 7,400+ invalid-user events to detect brute-force attempts. Configured real-time alerting yielding 2,799+ triggered alerts for incident review and firewall hardening.
